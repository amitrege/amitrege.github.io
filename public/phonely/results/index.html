Phone-agent fine-tune: results

We fine-tuned a small open model to answer business phone calls, and measured it against Claude Opus, the reference model. Every number on this page comes from a blind test on conversations the models never saw in training: a judge model reads two replies to the same moment of a real call, without knowing which model wrote which, and picks the better one.

Failure example

A banned phrase the tuned model still uses

  • One held-out business tells its agent, in writing, never to say filler phrases like “Got it”; Claude's rewrites use “Got it” all the time.
  • Every model tuned on those rewrites picked up the habit, and now breaks this business's written rule in a third to a half of its conversations.
  • Models tuned on, or replaying, the original calls never do; neither does Opus itself, which reads the rule fresh each time.

Training runs

Training run details

  • The training score (“loss”, roughly how far each practice reply is from its target) falls fast and levels off for all three imitation runs, with no spikes or instability.
  • The first correction pass is scored on a different scale and barely moves, which matches its coin-flip result above.

Method notes

How the judging works

  • For every held-out conversation, we showed Claude Sonnet (a different model from the reference, to avoid it favoring its own writing) the conversation so far plus two candidate replies, unlabeled, and asked which is better, or tie.
  • Every pair was judged twice with the reply order swapped; a win counts as 1, a tie as ½, and the two passes are averaged.
  • Whiskers and bracketed ranges are 95% confidence intervals, computed by resampling the conversations 2,000 times (fixed seed, so results are repeatable).
  • Test material: 150 held-out calls, 161 conversations from businesses never seen in training, and 150 validation conversations.
  • Two reliability checks: the judge's answer flips on 21% of comparisons when the reply order is swapped (shown in the stability chart above), and a second, different judge model agreed with the first on 78% of a 50-conversation sample.
  • The “Got it” counts are exact text matches against each business's own banned-phrase list.
  • After the GPU instance was lost and the model retrained, the new run was re-judged at 32.7% and 35.9% against the reference, consistent with the original 31.2% and 29.7% at these sample sizes.
  • A control run that sampled replies instead of using greedy decoding (always the most likely next word) scored 33.5% on validation next to 33.2% for greedy, so results are not an artifact of the decoding choice.
  • Everything on this page is rebuilt by one script from the raw judge outputs; no number was typed in by hand.
