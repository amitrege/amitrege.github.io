the long-horizon bind

Nothing outside the agent checked anything.
It judged its work by re-reading its own context.

You could wipe the context and start over.
But long-horizon work is one long trajectory. Wipe it and the agent loses what it learned. And some mistakes only surface deep into the run.

So the memory stays. The mistakes can't.

idea 1 · repair instead of reset

Keep the memory. Add a second loop
whose only job is to repair it.

work loop · every step
act→ observe→ remember↺
when something is wrong ↓
repair loop · runs only when needed
quarantine the bad belief→ fix the world-model→ re-test later↺

On the bad day, this removes one wrong belief and writes the correct one.
Everything else the agent knows survives. Nothing is wiped.

One question left. Who decides when something is wrong?
Not the agent. Grading its own work is how we got here.

idea 2 · surprise

Before every action,
predict what happens next.

every action now carries a prediction
process invoice #7 → “if I check later, its record will say processed”

Checked against what actually happens. A failed prediction can't be faked,
and it names the exact belief that was wrong.

act→ predict→ check↺
a prediction fails → the repair loop fires, at that belief

Surprise is the trigger. Reality is the judge. Watch it work.
